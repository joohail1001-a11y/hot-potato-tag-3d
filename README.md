# 🔥🥔 뜨거운 감자 술래잡기 3D

PC / 스마트폰 / 태블릿에서 실행 가능한 3D 웹게임입니다.

## 조작
- PC: WASD 또는 방향키 이동, 마우스 드래그 카메라
- 모바일/태블릿: 왼쪽 가상 조이스틱 이동, 오른쪽 화면 드래그 카메라
- 가로모드 권장

## 주요 기능
- 10개 랜덤 테마 맵
- AI 난이도 1~5
- 맵 몬스터와 1초 혼란 효과
- 속도 증가/감소 아이템
- 3초 비행 / 3초 땅속 잠복 아이템
- AI 장애물 회피 및 끼임 복구
- 숨겨진 뜨거운 감자 폭발 타이머
- 모바일 공유 / 전체화면 지원
